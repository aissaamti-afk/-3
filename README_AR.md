# مشترياتي — مشروع Android APK

هذا مشروع Android جديد يغلّف تطبيق مشترياتي HTML داخل WebView، ويعمل دون اتصال بالإنترنت.

## بناء APK باستخدام GitHub من الهاتف
1. أنشئ مستودع GitHub جديدًا باسم `Moutchriyati`.
2. ارفع **محتويات هذا المجلد** إلى المستودع في الفرع `main` (لا ترفع مجلد MoutchriyatiAndroid كطبقة إضافية إذا أردت أن يكون workflow في المكان الصحيح).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Moutchriyati APK** ثم **Run workflow**، أو انتظر البناء التلقائي بعد الرفع.
5. عند نجاح البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `Moutchriyati-debug-APK` ثم فك الضغط لتحصل على `app-debug.apk`.
7. افتح APK على هاتف Android ووافق على التثبيت من هذا المصدر إذا طلب الهاتف ذلك.

## ملاحظات
- هذه نسخة تجريبية debug وليست نسخة متجر Google Play.
- بيانات المشتريات تُخزّن محليًا داخل بيانات التطبيق. حذف التطبيق أو مسح بياناته قد يحذف الأرشيف.
- اختبر حفظ المشتريات بعد التثبيت، قبل الاعتماد عليه للاستخدام اليومي.
